# Suporte

> Canais oficiais de suporte dos projetos de **@cleitonSam**.

## Antes de pedir ajuda

1. Leia o README do repositório e a documentação em `docs/`.
2. Pesquise nas issues abertas e fechadas: o problema pode já ter resposta.
3. Confirme que está na versão mais recente e que as dependências foram instaladas com `npm ci` (ou equivalente).

## Onde abrir cada assunto

| Assunto | Canal |
| ------- | ----- |
| Dúvida de uso | Issue com template de dúvida ou Discussions |
| Bug reproduzível | Issue com template de bug |
| Sugestão de melhoria | Issue com template de feature |
| Vulnerabilidade de segurança | Security > Report a vulnerability (**nunca** issue pública) |
| Assunto comercial ou privado | Perfil [@cleitonSam](https://github.com/cleitonSam) |

## O que um bom relato contém

- O que você esperava que acontecesse e o que aconteceu.
- Passos mínimos para reproduzir.
- Versão do projeto, sistema operacional e runtime.
- Log ou stack trace completo, **sem credenciais e sem dados pessoais**.

## Prazos

Estes são projetos mantidos com esforço próprio. A meta é dar a primeira resposta em até 3 dias úteis. Itens de segurança têm prioridade sobre qualquer outro.
